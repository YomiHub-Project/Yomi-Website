Privacy Policy

Yomi-Office Open Source processes your documents on your own device — zero ads, zero telemetry, zero data selling.

Summary: All your Word, Excel, PowerPoint, and PDF documents, CamScanner captures, preferences, and recent-file lists remain strictly on your device. The app runs no telemetry servers, requires no mandatory account, and accesses the Internet only when you explicitly check for updates or invoke online features.

1. Your Data Stays on Your Device

Every core capability — Word editing, Excel calculations, PowerPoint presentations, PDF reading/merging/splitting, offline Vietnamese & English OCR, CamScanner, and MathType — runs locally on your Android phone or Windows PC.

  • Documents you create, edit, pin, or discover in the On This Device tab are never uploaded to project servers.
  • The app does not collect your name, email address, phone number, IMEI, GPS location, or contacts.
  • The Windows Portable edition stores settings next to its executable folder; standard Windows installs and Android store preferences inside OS-managed private app storage.

2. System Permissions We Request

Permissions are requested solely to perform direct document operations chosen by you:

  • Storage / "All files access" (Android 11+): Required to scan and open Office files stored in Documents, Download, or folders you pick, and to write edits back cleanly.
  • Camera: Requested only when you open CamScanner to photograph pages; captured images are processed locally into PDFs in the location you choose.
  • Network / Internet: Used exclusively for the optional network actions listed in Section 3 below.

3. When the App Connects to the Internet

You can stay completely offline and use 100% of core office features. Network requests happen only when you trigger or enable these specific actions:

  • Software update checks & downloads: When you check for updates (or leave automatic update checks enabled in Options), the app queries release metadata from GitHub Releases (primary source), Google Drive, or MediaFire (fallback mirrors). No personal identity or document content is transmitted; as with any HTTPS download, the hosting service receives standard network connection metadata such as your IP address under its own privacy policy.
  • Online A.I Assistant: When you use Web A.I or submit a prompt using an API key for OpenAI, Anthropic (Claude), Google (Gemini), or DeepSeek, the prompt text you submit is sent directly from your device to that provider. When using Offline mode or a local server (Ollama, LM Studio, or Free Claude Code over LAN), requests do not leave your local network.
  • Cloud Storage: When you sign in to Google Drive, OneDrive, Dropbox, or MediaFire to open or save files, the app communicates directly with that provider's official API within the permissions you grant.

4. Local Protection of API Keys & Credentials

If you enter personal A.I API keys or cloud sign-in tokens:

  • Windows: API keys are encrypted before storage using Windows DPAPI tied to your local Windows user account.
  • Android: Credentials are stored inside Android's private application sandbox, inaccessible to other apps.
  • Keys are never transmitted to YomiHub Project or any server other than the A.I or cloud endpoint you explicitly configure.

5. Quick Share & File Sharing

When you trigger Quick Share or the system share dialog, Yomi-Office hands only the selected document over to Android/Windows native sharing or the nearby device you pick. No cloud relay is operated by YomiHub Project.

6. Children's Privacy

Yomi-Office Open Source is a general-purpose office suite not directed specifically at children under 13 and does not knowingly collect or retain personal information from children.

7. Policy Updates & Open-Source Transparency

This policy takes effect on November 27, 2026. Because Yomi-Office Open Source is open source, you can inspect all networking and storage code directly on GitHub. Material changes in future releases will update this page alongside a new effective date.

8. Contact

For privacy questions or to report an unexpected issue, please open a thread at Yomi-Office Open Source GitHub Issues.
