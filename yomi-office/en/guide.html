1. Installing on Android

  1. Open Download › Android on your phone and download the matching .apk for your Android version and CPU (most phones from 2016 onward use Android 10+ arm64-v8a).
  2. Tap the downloaded .apk. On first sideload, Android prompts you to enable Install unknown apps for your browser or file manager — turn it on, return, and tap Install.
  3. On first launch on Android 11 or newer, grant All files access so the On This Device tab can scan and save Office files directly in Documents and Download.
Already have v0.1.7 or older? Just install the v0.1.8 APK over it — your settings, pinned files, and local notes stay intact.

2. Installing on Windows

  • Setup (.exe) — recommended: Download Yomi-Office-Open-Source-0.1.8-Win10-11-x64-Setup.exe (or the Win7-8.1 package on Windows 7/8.1) and run it. Because the installer is self-signed, SmartScreen may appear — click More info → Run anyway.
  • .msi Installer (new in v0.1.8): Double-click for standard Windows Installer UI, or run silently via msiexec /i Yomi-Office-Open-Source-0.1.8-Win10-11-x64.msi /passive.
  • Portable (.zip): Extract to any folder or USB drive and launch directly — no Admin privileges required and no Registry footprint.
  • .appxbundle (Windows 10 1809+ / 11): Download Yomi-Office-Open-Source-0.1.8-DevCert.cer alongside the bundle, double-click the .cer file → Install Certificate → Local Machine → Trusted People, then open the .appxbundle.
Windows 7 SP1 & 8.1: Be sure to download a build from the Win7-8.1 group (x64 or x86) or the Universal AnyCPU package. Windows 7 has no ARM64 build and requires .NET Framework 4.6.2+.

3. Home Screen & On This Device

Your start screen organizes documents into three clear tabs:

  • Recent: Files you recently opened or created.
  • Pinned: Keep important files pinned at the top for one-tap access.
  • On This Device (v0.1.8): Automatically scans your Documents, Downloads, and storage folders at launch and lists every Word, Excel, and PowerPoint file. Use the Rescan button anytime after copying new files to your device.

4. Word — Document Authoring

  • Opens and saves standard .docx, .docm (with VBA macros), .odt, .rtf, and .txt; exports cleanly to .pdf.
  • Full Ribbon layout: Format fonts, paragraphs, alignment, tables, images, charts, headers/footers, page numbers, automatic tables of contents, footnotes, and math equations.
  • Rulers & real pagination: Displays margins, tab stops, page breaks, and section breaks matching print output.
  • Mail Merge: Pull rows from an Excel spreadsheet or CSV file to batch-generate letters, invoices, or certificates.

5. Excel — Spreadsheets, 525 Functions & Links

  • 525 Excel 365 functions: Supports classic formulas (SUM, VLOOKUP, INDEX/MATCH, IFERROR) plus modern dynamic-array functions such as XLOOKUP, FILTER, SORT, UNIQUE, LAMBDA, LET, GROUPBY, and PIVOTBY.
  • Cross-sheet references: Reference cells across worksheets with =SUM(Sheet2!A1:A20) or =Sheet2!B5 * 1.1.
  • 3D sheet-range formulas: Aggregate across consecutive sheets with =SUM(Sheet1:Sheet3!A1).
  • Multi-workbook links: Pull values from external workbooks using =[Book2.xlsx]Data!A1 — ideal for roll-up financial or inventory sheets.
  • Analysis & automation: PivotTables, conditional formatting, data validation rules, and a built-in VBA macro editor (press Alt+F11 on Windows to edit code or Alt+F8 to run macros inside .xlsm files).

6. PowerPoint — Slide Decks & Presenter View

  • Edit .pptx, .pptm, and .odp decks with slide layouts, templates, transitions, and animations written back to standard `.pptx` files.
  • Presenter Console: View speaker notes, timer, and next-slide preview on your screen while the external monitor shows only the full-screen presentation.
  • Voice Narration: Record spoken audio directly onto individual slides.

7. PDF & Offline OCR

  • Read & annotate: Highlight, underline, freehand draw, add sticky notes, and sign PDF documents.
  • Document tools: Merge multiple PDFs, split pages, compress file size, extract embedded images, and add or remove PDF passwords.
  • Bidirectional conversion: Images ↔ PDF, and PDF → Word / PowerPoint / Excel / archival PDF-A.
  • Offline Vietnamese & English OCR: Extract searchable text (vie + eng) from scanned PDFs and photos without uploading files to external servers.

8. CamScanner — Document Scanning

  1. Open CamScanner inside Yomi-Office and point your camera at a printed page, receipt, or ID document.
  2. The scanner detects the 4 paper corners automatically; adjust the corners if needed and apply perspective correction.
  3. Choose a filter (Black & White Document, High Contrast, or Original Color), combine multiple pages, and export to PDF or run OCR immediately.

9. MathType — Equations

Write formulas using LaTeX or MathML syntax with live preview, then insert them directly into Word documents or PowerPoint slides.

10. A.I Assistant & Free Claude Code

Choose between five modes depending on whether you want pure offline privacy or online models:

  • Offline mode: Basic drafting, spellcheck, and formatting helpers with zero network traffic.
  • No-login Web A.I: Quick access to ChatGPT, Copilot, or Grok in the integrated panel.
  • Signed-in Web A.I: Use your own Gemini, Claude, or DeepSeek session.
  • Personal API key: Enter your OpenAI / Anthropic / Gemini API key — stored locally (encrypted via Windows DPAPI on Windows) and sent only to your chosen provider.
  • Local Models & Free Claude Code (new in v0.1.8): Connect Ollama, LM Studio, or Free Claude Code. Running fcc-server on your PC listens by default on http://127.0.0.1:8082. On an Android phone on the same Wi-Fi network, open A.I Assistant → Settings → Free Claude Code and enter your PC's LAN IP address (for example http://192.168.1.15:8082).

11. Cloud Storage & Conflict Detection

Connect Google Drive, OneDrive, Dropbox, or MediaFire right inside Yomi-Office. If someone else updates a shared cloud file while you are editing a cached copy, Yomi-Office warns you before overwriting so changes are not lost.

12. Samsung DeX, TV Display & Quick Share

  • Samsung DeX: On supported Galaxy devices (such as Galaxy Note 9 and newer), the interface expands automatically into a desktop-class Ribbon layout with multi-window support.
  • TV / Secondary Display: Output full-screen PowerPoint slide shows over HDMI or wireless casting (or test with Android's simulated secondary displays).
  • Quick Share: Hand off newly saved files directly to nearby phones or Windows PCs.

13. Software Updates

Open Options → Updates to check for new versions. The primary source is GitHub Releases, with Google Drive and MediaFire as fallback mirrors plus an editable custom GitHub repository field. On Windows, the updater supports fetching and installing new .msi packages directly.

14. Frequently Asked Questions

Which APK file should I download for my Android device?

Most phones released since 2016 use 64-bit ARM CPUs: download Android10plus-arm64-v8a.apk (or Android8-9-arm64-v8a / Android6-7-arm64-v8a for older Android versions). If Android refuses installation with "App not installed" on an older 32-bit device, switch to armeabi-v7a.

Which build should I use on Windows 7?

Pick a package from the Win7-8.1 group (Win7-8.1-x64 for 64-bit Windows 7 or Win7-8.1-x86 for 32-bit Windows 7). Do not use Win10-11 or .appxbundle builds on Windows 7.

Why do very large Excel workbooks take longer to open on mobile?

Workbooks containing tens of thousands of complex formulas, charts, or multi-workbook references require initial formula recalculation on mobile CPUs. Once loaded, everyday scrolling and edits become much smoother; closing heavy background apps can also help on older phones.

Is Setup.exe safe when Windows Defender SmartScreen warns on launch?

Yes — the installer is built from public source code on GitHub and signed with a self-signed certificate, which triggers SmartScreen until reputation builds up. You can verify the SHA-256 hash against SHA256_v0.1.8.md on GitHub Releases, then click More info → Run anyway.

Why can't my phone reach Free Claude Code running on my PC?

127.0.0.1 points to the phone itself. Find your PC's local Wi-Fi IP address running fcc-server (e.g., 192.168.1.20), allow port 8082 through Windows Firewall, keep both devices on the same Wi-Fi, and enter http://192.168.1.20:8082 in Yomi-Office on Android.
