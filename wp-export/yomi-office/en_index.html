Yomi-Office Open Source

A free, open-source office suite that runs offline on Android 6.0+ and Windows 7+: Word, Excel, PowerPoint, PDF, CamScanner, MathType, and A.I Assistant — opening Microsoft Office and OpenDocument files with all your data kept on your device.

Features

One suite in place of half a dozen separate apps: documents, spreadsheets, presentations, PDFs, and camera scanning — with a familiar Ribbon interface.

📄

Word

Full Ribbon, rulers, real pagination and page breaks, Mail Merge from Excel, tables of contents, footnotes, equations, and VBA macros (.docm).

📊

Excel

525 Excel 365 functions, cross-sheet, 3D, and multi-workbook formulas [Book.xlsx]Sheet!A1, PivotTables, conditional formatting, data validation, and VBA macros (.xlsm).

📽️

PowerPoint

Slide shows, transitions and animations saved back to .pptx, Presenter Console, voice narration recording, VBA macros (.pptm), and templates.

📕

PDF

Read, annotate, sign, add/remove passwords, compress, merge, extract images, images ↔ PDF, PDF → Word/PowerPoint/Excel/PDF-A, and offline Vietnamese + English OCR.

📷

CamScanner

Capture documents with your camera, auto-detect page edges, correct perspective, apply black-and-white document filters, and export to PDF.

∑

MathType

Write mathematical equations using LaTeX or MathML and insert them directly into Word documents and PowerPoint slides.

✨

A.I Assistant

Offline mode; no-login web A.I (ChatGPT, Copilot, Grok…) or signed-in web (Gemini, Claude, DeepSeek); local API keys; Free Claude Code, Ollama, and LM Studio.

🗂️

On This Device NEW

Automatically scans your storage on startup and lists every Word, Excel, and PowerPoint file under the On This Device tab.

☁️

Cloud

Google Drive, OneDrive, Dropbox, and MediaFire with conflict detection when multiple people edit the same file.

🖥️

DeX & TV

Desktop layout on Samsung DeX, presentation output to a TV or secondary display, and Quick Share file sending.

🔄

Auto-Update NEW

Checks for updates from GitHub Releases (primary source), Google Drive, and MediaFire; downloads and installs right inside the app.

What's New in v0.1.8

Released November 25, 2026 — see full details in the release notes.

✨ New Features

  • Renamed to Yomi-Office Open Source with a fresh new logo.
  • On This Device tab: auto-scans Word, Excel, and PowerPoint files on launch.
  • Free Claude Code in A.I Assistant (free proxy, defaults to http://127.0.0.1:8082).
  • Software updater powered by GitHub Releases; new Windows .msi installers.
  • Android split into 9 APKs (Android version × CPU architecture) — ~73% smaller each.

🛠️ Fixed Issues

  • Fixed Office file auto-scan on startup (broken since v0.1.6).
  • Fixed updater missing GitHub Releases source and Windows .msi assets.
  • Fixed Settings dialog horizontal overflow on portrait phone screens.
  • Cleaned up legacy logos and hardcoded old version labels across the UI.
