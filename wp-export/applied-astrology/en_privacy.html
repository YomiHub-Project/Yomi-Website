Privacy Policy

Applicable to Yomi-Applied Astrology (Yomi-Tử Vi Ứng Dụng) • Last updated: November 2026
🛡️ Core Principle: Yomi-Applied Astrology is designed as an Offline-First application with respect for user privacy. We do not collect, transmit, or store personal data on external servers.

1. 100% Offline-First Architecture

All calculations for astrological charts, lunar-solar conversions, the 611-article Bửu Đình research library, and search assistants reside and compute entirely on your local device. The application requires no account, no login, and no internet connection to build charts, use the lunar calendar, read the library or use the assistant.

2. Local Data Storage Only

All user input (such as birth data profiles, bookmarks, reading history, and Liquid Glass appearance preferences) is stored strictly in your device's private storage:

  • Android: Stored within private SharedPreferences sandbox, inaccessible to other apps.
  • Windows: Stored in %APPDATA%\AppliedAstrology\store.json or the portable userdata\ directory.

This data remains entirely under your control and is completely removed upon uninstalling the application or clearing app data.

3. The Only Automatic Connection: Update Checking

The only network connection performed by the application is a secure read query to GitHub's public API endpoint: https://api.github.com/repos/YomiHub-Project/Applied-Astrology-T-Vi-/releases/latest.

  • Triggered only when you manually click "Check for Updates" or upon launch (if update checking is enabled).
  • The app only reads the latest version information; when you accept an update, the installer is downloaded from GitHub Releases. No device identifier, account or chart data is sent. Like any web server, GitHub sees the IP address of the connection and handles it under GitHub's own privacy policy.

3b. Connections only when you tap them

  • Translate (when reading an article in a language other than Vietnamese): opens Google Translate in your browser with the article text; Google's policy applies there.
  • Share, open links, report a bug: only through the app or browser you pick; the app never sends crash reports by itself.

4. Zero Advertising & Zero Telemetry

Yomi-Applied Astrology guarantees:

  • No third-party ad networks (AdMob, Unity, Facebook, etc.).
  • No analytics or user behavior tracking SDKs (Google Analytics, Firebase, etc.).
  • No access to GPS location, contacts, microphone, camera, or sensitive device sensors.

5. Image Export & QR Code Sharing

When exporting chart PNG images or generating QR codes, everything is generated on-device using local algorithms. Sharing actions are handled exclusively through your operating system's native share sheet.

6. Open Source Transparency

Yomi-Applied Astrology is developed with full transparency. The complete source code is publicly inspectable at the GitHub Repository. Anyone may review the code to verify our privacy practices.
