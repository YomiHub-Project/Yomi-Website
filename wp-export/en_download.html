📱 Android 7.0 and later

For phones and tablets running Android 7.0 or later. If you are unsure which build to choose, try arm64-v8a first.

  • arm64-v8a
    For phones or tablets running 64-bit ARM Android.
  • armeabi-v7a
    For devices running 32-bit ARM Android.
  • x86_64
    For devices or emulators running 64-bit x86 Android.
When updating, install the new APK over the existing build to keep your data. Creating a backup first is recommended.

📲 Android 6.0

Choose this group for devices running Android 6.0. Select the APK matching your device’s architecture.

  • arm64-v8a
    For Android 6.0 devices running 64-bit ARM.
  • armeabi-v7a
    For Android 6.0 devices running 32-bit ARM.
  • x86_64
    For Android 6.0 devices or emulators running 64-bit x86.
If Android prompts you to allow apps from unknown sources, allow installations from the source you are using to open the APK.

📺 YumiHub Android TV

Choose an APK matching your TV or TV box architecture. The interface supports directional pad (D-pad) navigation.

  • arm64-v8a
    For Android TV or TV boxes running 64-bit ARM.
  • armeabi-v7a
    For Android TV or TV boxes running 32-bit ARM.
  • x86_64
    For Android TV devices or emulators running 64-bit x86.
The TV edition focuses on movies and anime. Comics, novels, Google Play Books, Booru and the Personal Bookshelf are hidden.

📺 Samsung TV (Tizen 3.0+) — preview

For 2017+ Samsung Smart TVs running Tizen 3.0+ (Movies & TV only), preview, not on Samsung Apps. The signed .wgt installs only on TVs whose DUID is in the certificate (see the note below).

  • Source Tizen 3.0+
    Source folder tizen/ at https://github.com/YomiHub-Project/YomiHub-Project/tree/main/tizen to package and sign with Tizen Studio CLI.
  • YumiHub-SamsungTV-0.6.7.wgt
    Preview. The signed package installs only on TVs whose DUID is in the Samsung certificate that signed it: currently the Samsung UA55MU6500 (55" MU6500, 2017, Tizen 3.0) with Developer Mode on, installed via Tizen Studio. Other Samsung TVs (2017+) need the package re-signed with a Samsung certificate that includes their DUID; source in tizen/.
Test installation: on the TV open Apps, press 1 2 3 4 5 to enable Developer Mode, enter your PC IP, then install the signed .wgt using Tizen Studio CLI (sdb). See Samsung TV (Tizen) guide.

🖥️ Windows 10 and 11 (x64)

Choose Setup.exe for a standard installation, or choose the ZIP build to extract and run. Every Windows package includes Java and M-Extension-Server for APK extensions – nothing else to download.

  • Setup.exe
    Installer for 64-bit Windows.
  • .appxbundle package
    The AppX package requires the certificate and two scripts below.
  • YomiHub-RootCA.cer
    Root certificate for the AppX package.
  • Install-YomiHub.bat
    Launcher for the AppX installer.
  • Install-YomiHub.ps1
    PowerShell script invoked by the batch file.
  • Portable ZIP
    Extract the archive and open the application folder (M-Extension-Server included).
If you choose AppX, download the .appxbundle package, the .cer certificate and both .bat and .ps1 files into the same folder. Verify the SHA-256 hash for each file before running Install-YomiHub.bat.

🔎 Verify downloaded files

SHA-256 hashes and file sizes for version 0.6.7 are pending verification. File names and links below should be checked against the Release before announcement. Use the SHA-256 list corresponding to your downloaded version.

  • SHA-256 checksums
    Open to look up hashes by file name.
  • Release changelog
    View all changes in version 0.6.7.

On Windows, open PowerShell in your download folder. Replace the file name in the following command with the file you want to check.

Get-FileHash -Algorithm SHA256 -LiteralPath ".\YomiHub-0.6.7-windows-x64-Setup.exe"

In Command Prompt, you can run certutil -hashfile "YomiHub-0.6.7-windows-x64-Setup.exe" SHA256.

On Android, open the APK in a file manager with a checksum utility, then select SHA-256.

Compare all 64 characters with the line matching the file name in the SHA-256 list. Uppercase and lowercase letters are treated equally. If the hash does not match, download the file again from GitHub Releases and check it before opening.
