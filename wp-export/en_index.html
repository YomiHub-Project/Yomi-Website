YomiHub

YomiHub is an open-source app for reading comics and novels, watching movies and anime, using Google Play Books and Booru, and managing your print collection. It runs on Android 6.0 or later and Windows 10/11 x64. The YumiHub Android TV edition focuses on movies and anime. YomiHub is built on Mangayomi with Flutter.

What’s new in 0.6.7 · 3 new features · 8 fixes · 4 stability improvements

✨ New features & stability0.6.7

  • YumiHub for Samsung Smart TV (Tizen 3.0+, 2017+) — preview: a Tizen Web App (.wgt) with Movies & TV only, 5-second splash, Library · Updates · Browse · More sidebar, saved watch position, library import from a YomiHub backup and Samsung remote support (arrows/OK/Return, Play/Pause/Stop/seek, colour keys A–D); installed via Developer Mode (requires a Samsung certificate).
  • Checking extension repos for updates now names the failing repo and reason (DNS, timeout, HTTP <code>, bad format) instead of only a count.
  • Extension error logs include the source ID and extension version; repo addresses in logs are cleaned (no credentials, query or fragment).
  • Stability improvements: new automated tests (local images, image host breaker, repo rename, global search, Issue #2); automatic ES5 syntax check and .wgt packaging in GitHub Actions; 65 languages updated; official website at yomihub-project.github.io/Yomi-Website and mirror on WordPress.

🐛 Fixes8 items

  • Covers stored on the device (content://, file:// — Bookshelf, local folders) did not show.
  • Images from a failing host (e.g. cdn.donmai.us) are paused for 30 s after 8 errors in a row instead of retrying hundreds of times per minute.
  • The default extension repo is renamed YomiHub Extension Repo (YomiHub-Project/YomiHub-Extension-Repo) — existing repos move automatically and installed extensions keep updating (Issue #2).
  • Global search stays within the concurrent source limit (new requests no longer jump the queue).
  • Global search skips sources whose domain no longer resolves (DNS) for 10 minutes.
  • UI no longer freezes ~2.4 s while previewing a large backup.
  • The player keeps the watch position when a video server fails mid-playback and switches servers.
  • The Windows diagnostics screen no longer mentions the retired -full.zip package (merged into .zip since 0.6.6+60) across 66 languages.

Known issues: the player can stall 3–4 s when switching servers (being investigated for 0.6.8); the Samsung TV app is a preview; TeraBox is not supported; Android 6 still has TLS-limited sources. Full details: 0.6.7 release notes · v0.6.7 on GitHub.

What’s new in 0.6.4 · November 21, 2026

✨ New features4 additions

  • Releases related to your bookshelf – a news bar with new books from Kim Đồng, Trẻ, IPM, AMAK and Hikari that match the series on your Personal Bookshelf; choose news sources and types (Limited, Artbook, Poster, ColorWalk, DataBook, Boxset), hide news or ignore a series
  • Recognise a cover from a photo – take or pick a photo of an old book without a barcode and the bookshelf suggests the series with the most similar cover
  • Image translation with your own Frank Yomik server (speech-bubble translation, furigana, webtoon); if the server fails, the built-in translator is used
  • Extension repositories that only publish index.json (or only index.min.json) can be added with either name

🐛 Fixes and improvementsUpdated in 0.6.4

  • Tor finishing at 100% right at the 90-second limit is no longer reported as "not connected" – YomiHub uses Tor as soon as the circuit is ready
  • HLS videos through the ad filter no longer fail with Failed to open: if the playlist cannot be read, playback goes straight to the origin server
  • APK extensions (Mihon/Aniyomi) no longer wait 3 minutes when browsing, searching or opening pages: they stop after 90 seconds, retry once through Tor and show a clear error
  • Removed extension repositories (404/410/451) are reported once with instructions instead of an error on every refresh

Personal Bookshelf

Updated in 0.6.4
  • Manage your print comics and books offline, with data stored on your device. Turn the feature on or off under Enable/Disable Features & Extension Sources
  • Search by title or volume number without typing accents (for example, One Piece 105). See the Owned / Standard edition owned / Not purchased badges and your six most recent series
  • Scan ISBN barcodes and look up books on Google Books or Open Library. Check for duplicates by series, volume and edition
  • Select a range of volumes at once (such as 1–10 or 1–100). Purchased volumes automatically leave your Shopping list. For ongoing series, the app suggests the next volume
  • Find missing volumes, manage your Shopping list, and keep limited editions, extras and photos together. View statistics, import or export CSV files, and include your collection in app backups. Unavailable on Android TV
Read the bookshelf guide

VPN, DNS & automatic Tor switching

Updated in 0.6.4
  • Automatically switch to Tor when a site is blocked: when Tor is running, the app can retry blocked requests through Tor, including those from APK extensions and cover image requests that return an HTML block page
  • Use Tor with Snowflake, obfs4 or meek bridges. Choose Automatic to try them in turn if a connection is blocked. Other options include Cloudflare WARP, OpenVPN, WireGuard and VPN Gate
  • DNS over HTTPS, ad blocking, and automatic or manual handling of Cloudflare challenges in WebView
  • Choose which extensions, WebViews and browser sessions use Tor or a proxy. On Android, WARP, OpenVPN, WireGuard and SoftEther carry all of YomiHub’s traffic

  • Merge duplicate titles, select titles manually, or group them by extension

Extension repositories and new filters

Updated in 0.6.4

  • Get suggestions for new extension repositories and change a URL or domain when a site moves
